# Henry2.0
My portfolio page 2.0

## Blog

`blog.html` and `article.html` add a lightweight editorial section with a Google Sheets backend, anonymous likes, and moderated comments. `admin.html` is the private, server-authenticated writing and moderation desk. The existing Medium archive remains visible when the backend is unavailable.

See [BLOG_SETUP.md](BLOG_SETUP.md) for the one-time Google Sheet, Apps Script, and Netlify setup.
